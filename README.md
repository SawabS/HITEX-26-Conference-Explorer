# Hitechs 26 Conference Explorer

[Live explorer](https://SawabS.github.io/Hitechs-26-Conference-Explorer/) · [GitHub repository](https://github.com/SawabS/Hitechs-26-Conference-Explorer)

An independent research and planning interface for the HITEX 2026 conference programme (Erbil International Fairground, 6–9 October 2026). Not affiliated with HITEX.

**Designed and built by Sawab Sarkavri.** GitHub: [@SawabS](https://github.com/SawabS)

## What it does

- **Overview**: live conference status in Erbil time (current and next session), programme statistics, day cards and a Technology-day spotlight.
- **Schedule**: a proportional timeline (block width = real session length, gaps drawn to scale, long breaks optionally compressed and labelled), a vertical phone timeline, an agenda list, a "what's on at HH:MM" probe, theme highlighting and a Now marker.
- **Session and speaker sheets**: side sheets on desktop, spring bottom sheets on phones, with participant groups, moderators, related sessions, co-presenters and source attribution.
- **Speakers**: searchable grid with filters for day, track, session type, role, organisation and expertise.
- **Explore**: theme explorer (multi-theme shortlists you can save), a theme × day matrix, sessions-by-theme chart (Recharts), schedule density and format-length charts, and a chronological speaker ↔ session ↔ organisation network.
- **My Schedule**: bookmarks in `localStorage`, conflict detection, total time, next selected session, `.ics` export, copy as text, print styles.
- **Day briefings**: audio overviews of each programme day in a full-screen player. A navy light field with a restrained rose accent reacts to the voice (loudness, frequency bands and pitch from a precomputed envelope), the transcript is lit word by word in Live mode or read in full in Transcript mode with click-to-seek and follow-along scrolling, chapters link each passage to its session, and a mini-player keeps the audio going while browsing. Keyboard: Space or K play/pause, arrows ±5 s, J/L ±10 s, T switches mode, Esc minimises. Deep link: `/?listen=2026-10-07`.
- **Search**: command palette on ⌘K / Ctrl+K (or `/`) across sessions, people, organisations, themes and formats.

## Stack

Next.js 16 (App Router, all routes statically pre-rendered), React 19, TypeScript, Tailwind CSS 4, Motion, Lucide, Recharts. Dark-only design on a night-navy ground with a faint grid. Fonts: Outfit and Plus Jakarta Sans (HITEX's typefaces, open-licensed via Fontsource) and Geist Mono for times.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm run lint && npm run typecheck
```

Static export (any static host): `STATIC_EXPORT=1 npm run build` writes `out/`.

## Data and provenance

| Layer | File | Source |
| --- | --- | --- |
| Official programme | `data/hitex-2026.official.json` | Generated from https://www.hitex.tech/en/conferences/agenda |
| Curated enrichment | `data/enrichment.ts` | Organisation normalisation, expertise and theme tags, external sources |
| Typed model | `lib/data.ts` | Merges both into `Session` and `Speaker` records with `sources` |

`scripts/update-hitex-data.ts` re-fetches the agenda. The page is server-rendered with React Router and embeds its loader data as a turbo-stream payload; the script decodes that payload (sessions, times, formats, speaker titles, biographies, portrait URLs and moderator flags). No private endpoint is used.

```bash
npm run data:update                          # fetch live
npm run data:update:file -- ./agenda.html    # parse a saved copy
```

Rules the dataset follows:

- Only people on the 2026 agenda are listed; the HITEX speaker archive is not treated as the 2026 line-up.
- Organisations are recorded only where the official title, company field or biography names them, and the UI says which.
- HITEX published no 2026 session descriptions and no opening-ceremony time; both are shown as not published.
- Five people have no official biography. Hiwa Afandy (an article he authored, Kapita) and Dr. Shamal Al-Duhoki (his personal academic website, shamal-dohuki.github.io) are enriched from cited public sources; the others show "Biography not publicly listed".
- Theme tags are analytical, derived from official titles and participant profiles, and labelled as such.

Last research pass: 6 Oct 2026 (official agenda last updated 4 Oct 2026).

## Day briefings (audio)

The briefings were generated by the site owner with NotebookLM from the day documents in `scripts/export-day-briefs.ts`. `scripts/podcasts/transcribe.py` transcribes them locally with NVIDIA Parakeet TDT 0.6B v2 (int8, via sherpa-onnx; model from the sherpa-onnx GitHub releases) and keeps token timestamps. `scripts/podcasts/build.py` turns those into `data/podcasts.generated.json`: word timings, sentences, names corrected to the official agenda spelling, chapters matched to sessions by the times the host reads out, and a 30 fps envelope. It also writes `public/podcasts/<date>.mp3` (96 kbps mono). All three programme days are included. To rebuild an individual briefing, run `python3 scripts/podcasts/build.py <asr_dir> <project_root> day3` (or `day2` / `day4`) after transcription; other episodes are preserved.

## Imagery

`public/campaign/*.webp` are night photographs of the HITEX 26 outdoor campaign in Erbil supplied by the site owner, cropped to remove the HITEX wordmark overlay so the explorer does not present HITEX's logo as its own. `public/portraits/<speakerId>.webp` are the speakers' official HITEX 2026 agenda photos (all 49), cropped square around the face with OpenCV and saved at 256 px. Official photos were chosen over LinkedIn or social-media images because they are supplied by the speakers to HITEX, so each one is certain to show the right person. `lib/portraits.ts` maps speaker ids to the files; the preview build inlines the same files.

## Project layout

```
app/                 routes: /, /schedule, /speakers, /explore, /my-schedule
components/
  conference/        shell, overview, day navigator, session sheet
  timeline/          horizontal timeline, phone timeline, agenda list, schedule view
  speakers/          speaker grid and profile sheet
  charts/            theme chart, theme × day matrix, density and duration charts
  graph/             relationship network
  search/            command palette
  planner/           My Schedule
  ui/                avatar, sheet, badges, photo band
data/                official JSON, enrichment, themes
lib/                 data model, navigation contract, planner store, insights, search, ics
scripts/             data ingestion
preview/             single-file build of the same views (Vite) for embedding
types/               shared types
```

URL state: `/schedule?day=2026-10-08&session=trust-no-one`, `/speakers?speaker=hiwa-afandy`, `/explore?topic=ai,enterprise&section=network`, `/schedule?day=2026-10-08&at=15:30`.

## Single-file preview

`npm run preview:build` bundles the same components into `preview/dist/index.html` (routing via `preview/memory-nav.tsx`, `next/image` and `next/dynamic` replaced by small shims). In that build portraits are inlined as data URIs, and file downloads and printing are hidden.

## GitHub Pages

Pushes to `main` build and deploy the full static Next.js app through `.github/workflows/pages.yml`. In repository Settings → Pages, select **GitHub Actions** as the source.

The workflow sets `STATIC_EXPORT=1` and `NEXT_PUBLIC_BASE_PATH=/Hitechs-26-Conference-Explorer`, including this prefix for portraits, podcasts and native history navigation. For a local root deployment, omit `NEXT_PUBLIC_BASE_PATH`.
